# 213123 — حزمة بناء APK

- اسم الحزمة: `com.apkstudio.213123x8aw`
- الإصدار: `1.0.0`
- المصدر: https://multyapp.site.je/

## خطوات البناء
1. ثبّت Android Studio (أو Gradle + Android SDK).
2. افتح مجلد المشروع هذا.
3. انتظر مزامنة Gradle.
4. من القائمة: Build → Build Bundle(s)/APK(s) → Build APK(s).
5. ستجد ملف APK في: app/build/outputs/apk/debug/

> ملاحظة: هذا مشروع WebView جاهز. يمكنك تعديل الأيقونة والاسم من مجلد res.
